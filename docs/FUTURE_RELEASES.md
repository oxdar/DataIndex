# Version roadmap after FIRST v0.1.0

- **v0.1.0 — Foundation:** independent core + two free plugins + optional reasoning + test-only premium gating. No paid business product yet.
- **v0.2.x — Developer utility:** broader document formats, live-verified experimental database engines (Snowflake, BigQuery, ClickHouse), improved evidence cross-links, SDK/MCP, better benchmarks.
- **v0.3.x — Free multimodal:** Visual basic + Geometry basic; native object locators and validation.
- **v0.4.x — First commercial pilot:** one narrow premium module (likely BIMIndex Pro OR SubsurfaceIndex Pro) with dedicated value proposition; private deployment and real entitlement integration.
- **v0.5+ — Broader engineering:** CAD, reality, advanced subsurface, enterprise connectors as separate packages only if demand and integration quality justify them.

Versions are product-planning hypotheses, not dates or commitments. Skip/cut features based on test and pilot evidence. Do not lock commercial price or license into hardcoded package version assumptions.
